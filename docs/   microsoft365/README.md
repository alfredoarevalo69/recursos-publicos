## Documentación y Guías Disponibles en este Directorio

Este directorio recopila especificaciones técnicas, guías de despliegue y análisis de arquitectura orientados a la administración moderna de endpoints y servicios de identidad en la nube de Microsoft.

### 1. Empaquetado y Despliegue de Aplicaciones Win32 con Microsoft Intune
* **Descripción:** Guía técnica paso a paso para empaquetar, desplegar y validar aplicaciones Win32 (`.exe`) en entornos administrados por Microsoft Intune, asegurando ejecución bajo privilegios de la cuenta del sistema (`NT AUTHORITY\SYSTEM`) y reglas de detección robustas.
* **📄 Documento PDF:** [Descargar / Consultar Especificación](./empaquetado-despliegue-apps-win32-intune.pdf)

### 2. Fundamentos y Arquitectura de Autoservicio de Restablecimiento de Contraseña (MS SSPR)
* **Descripción:** Análisis técnico sobre la implementación, flujos de autenticación multifactor (MFA), integración con directorios híbridos y políticas de seguridad para el Autoservicio de Restablecimiento de Contraseña en Microsoft Entra ID.
* **📄 Documento PDF:** [Descargar / Consultar Especificación](./Que-es-Microsoft-SSPR.pdf)
